# Panorly

**Panorly** is a modern, minimal, and fully customizable self-hosted application dashboard.

Organize links to all your apps and services in one place, with a UI that adapts to *you*: custom background images, color themes, and layout preferences per user — exportable and portable as JSON.

## Features (planned/in progress)

- Clean, minimal dashboard for organizing links to your self-hosted apps and services
- Multi-user support with secure authentication
- Per-user custom themes: colors, background image, layout density
- Theme export/import as JSON (portable between installations)
- Docker-first deployment

## Status

This project is under active development. See the [project board](../../issues) for progress.
